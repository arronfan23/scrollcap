# 自动滚动验证

代码检查：运行 `./scripts/test.sh`，包含 15 项基础拼接、31 项裁剪、20 项自动滚动和 41 项视频检查。

实际窗口：运行 `./scripts/build-fixture.sh`，打开 `work/ScrollCapFixture.app`。测试窗口含固定标题、24 条唯一编号消息和固定输入框；菜单「测试」可回到顶部、去到底部、切换原生和 WebKit 网页。

1. 在已获系统授权的 Applications / ScrollCap 中选择自动模式、慢速和向下。
2. 框选测试窗口的内容区（640 × 580 点），标记固定顶部 60 点、正文 450 点和底部 70 点。
3. 等待自动到底，保存 PNG，确认 SCAP-01 至 SCAP-24 齐全、顺序正确，HEADER-ONCE / FOOTER-ONCE 各一次。原生完整图应为 2070 点高，Retina 下为 4140 像素。
4. 菜单去到底部，选择向上，重复验证；切换网页后重复向下和向上。
5. 分别验证结束按钮、移动鼠标、切换前台应用、移动目标窗口能停止；中途结束仍可生成已采集内容。

`work/fixture.json` 记录测试目标位置、缩放比例和实际滚动偏移，用于核对确实到达首尾。测试素材为合成内容，无私人聊天。

真实窗口测试必须使用 ScrollCap 自己获得的系统权限。代码检查通过不代表真实录屏、输入权限和目标窗口滚动均已验证。

## 2.3.0 本机实测（2026-10-15）

通过已安装 ScrollCap 自身授权，操作真实 NSScrollView 与 WKWebView 窗口采集。原生向上 / 向下、网页向上 / 向下均得到 1280 × 4140 PNG；逐行以原始分辨率 OCR 验证 SCAP-01 至 SCAP-24 顺序完整，固定 HEADER-ONCE 与 FOOTER-ONCE 各一次。实际窗口偏移分别到达 0 / 1490 点，分析报告均无缺失重叠警告。PNG 另做目视检查。

整张长图直接 OCR 会因缩小而漏识别编号，验证器因此分别识别每个已知测试行，原始识别文本也写入验证记录。验证器源码为 `Tests/Fixtures/VerifyCapture.swift`，验证 PNG、窗口状态与处理报告保存在本地忽略目录 `work/auto-validation/`。

这些结果覆盖本机合成测试窗口；聊天应用的分页加载、悬浮组件、视频动画仍可能影响拼接，无法确认时软件会提示并保留原视频。

中断验证：菜单结束截图能保存已采集部分；鼠标移出会停止。测试菜单可安排收到首个滚轮后 3 秒移动 / 隐藏自身窗口，用来验证目标移动和前台离开。移动 40 点后录制在 5.8 秒结束，末尾未对齐时给出部分结果提示并保留原视频。
隐藏自身窗口后录制在 4.8 秒结束，偏移停在 180 点，保留已确认部分并提示保存原视频。直接操作目标窗口的测试期间，应避免自动化工具自身移动鼠标导致提前停止。
