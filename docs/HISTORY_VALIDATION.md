## 合成样本界面操作

使用独立设计预览及其隔离的本机历史目录。普通样本为 2240 × 2160 px，长图样本为 2240 × 5840 px；这些样本用于验证结果编辑和历史管理，不代表正式版已经完成真实屏幕采集复测。

| 操作 | 已验证结果 |
| --- | --- |
| 默认保留方式 | 新截图直接 Esc 不进入历史；复制后进入历史 |
| 重复复制 | 对同一截图连续复制两次，历史仍只有一条 |
| 保存历史编辑 | Command + S 更新原记录，不弹出文件保存面板 |
| 放弃历史编辑 | Esc 丢弃本次未保存修改，保留历史上次保存版本 |
| 重新启动 | 重启预览应用后，历史记录及内容仍存在 |
| 重复置顶 | 复用同一截图文档，未创建相互独立的重复编辑状态 |
| 工作台与浮层独立 | 工作台复制后进入历史，在历史中添加马赛克并保存；工作台再次复制生成独立的原图记录，已有历史中的马赛克仍保留 |
| 查找记录 | 输入截图类型搜索，可正确过滤记录 |
| 删除当前编辑项 | 删除正在编辑的长图历史记录，同时关闭对应编辑窗 |
| 取消全部删除 | 取消清空操作后，历史数量不变 |
| 全部删除 | 确认清空后历史数量为 0 |
| 外部导出文件 | 删除历史前后，已导出 PNG 的 SHA-256 一致 |
