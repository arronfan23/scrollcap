# Privacy

ScrollCap 的录制、视频解码、配准、文字识别与长图合成都在本机完成。当前应用源码没有云端 API 调用、账号登录、遥测、广告或网络上传功能。

## 数据生命周期

- 普通截图直接读取用户框选区域，不录制视频。浮层窗口不会在退出应用后自动恢复；已保留的截图可以从历史重新打开。
- 默认保存方式为「保存/复制后保留」：只有保存或复制成功的截图才进入本机历史。直接按 Esc 或叉号关闭尚未保留的新截图，会丢弃该截图及其未保存标注。
- 设置中可选择「所有截图自动保留」：采集结果生成后即加入历史，关闭新截图时保留最终标注。
- 历史存放于本机 `~/Library/Application Support/ScrollCap/History`，保留原始图片、可编辑标注、缩略图以及日期、截图类型和尺寸等信息，不随临时会话清理。
- 从历史重新编辑时，保存图标、Command + S 或复制会更新同一条记录。Esc 会放弃本次未保存的修改，保留历史上次保存版本。Option + Command + S 可另存 PNG。
- 工作台裁剪原图的导出与浮层标注版本使用独立历史记录，保存其中一份不会覆盖另一份。
- 自定义快捷键、自动置顶和历史保存方式偏好保存在本机 UserDefaults。快捷键通过系统注册接收指定组合，不监听或记录日常键盘输入。
- 框选完整窗口后保存一张初始画面，用于保留固定顶部和底部。
- 连续录制写入本机临时 MOV 文件，不录制音频，不显示鼠标指针。
- 拼接阶段生成关键帧 PNG 与 JSON 分析报告，报告包含帧位置、尺寸、接缝位置和处理警告。
- 用户导出时，截图 PNG、视频或关键帧写入所选位置。复制截图会将合成后的图片写入系统剪贴板。
- 开始下一次采集或正常退出时，当前会话临时目录清理，历史截图保留。已有导入视频不会被修改或删除。异常退出可能留下临时文件。

## 可编辑原图与删除

历史保留原图与可编辑标注，因此在历史中可以移除马赛克或其他遮挡，查看原始像素。历史记录并非脱敏后的分享文件。导出 PNG 和复制图片时，文字、图形和马赛克会合入图片像素，不附带可还原原图的标注图层或原始图片；导出后，历史中的可编辑原图仍会保留。

在「历史截图」中删除单项或全部记录，会将对应数据移到系统废纸篓，不会删除已导出到其他位置的文件。移入废纸篓的原图和标注仍可恢复；需要彻底移除时，可在系统废纸篓中处理。

请在退出前保留需要的截图，并另行导出需要的视频、关键帧和报告。通过 GitHub 上传样本是你自己的独立操作；应用不会自动上传。

## 系统权限

实时采集需要屏幕录制权限。自动滚动另外需要辅助功能权限，向用户选定的正文位置发送滚动事件；首次滚动时将鼠标定位到正文中央。仅在用户开始自动采集后执行。切换应用、移动鼠标或目标窗口都会停止，点击结束会终止正在发送的滚动。手动模式不要求辅助功能。视频导入和预览裁剪不需要屏幕录制权限。

短时权限检查和滚动进程来自同一个签名应用，不借用其他应用的授权，不修改系统隐私数据库。

裁剪在内存中保留原图和像素选区。保存和复制时仅导出选区，原视频和关键帧不会被裁剪或改写。

Logo 和仓库展示素材的制作不属于应用的运行流程；仓库示例画面来自合成测试窗口。
