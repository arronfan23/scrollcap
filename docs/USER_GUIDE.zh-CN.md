# ScrollCap 截图工具

SMO 出品的 macOS 截图工具，应用窗口标题为 ScrollCap。普通截图可拖动框选，在原位置停留并标注、置顶；长截图像 FSCapture 一样保留聊天窗口的固定顶部和底部，中间正文连续拼接。支持网页和聊天窗口、手动和自动滚动，两种截图都能在主界面预览中拖动裁剪。

## 安装

按设备下载 arm64（Apple 芯片）或 x86_64（Intel）安装包，打开 DMG，把「ScrollCap.app」拖到 Applications。需要 macOS 14 或更新版本。旧版「长截图」可以保留。

首次框选屏幕时，按提示在系统设置 → 隐私与安全性 → 屏幕与系统音频录制中允许「ScrollCap」。如系统要求，退出并重新打开应用。**手动采集无需辅助功能权限**；自动模式需要另外开启辅助功能。

新版使用独立的应用身份，旧版的权限不会自动转移。建议先安装到 Applications，再开启权限，之后始终从该位置启动。

## 普通截图与置顶

1. 选择「普通截图」，点击「框选普通截图」，或按 Control + Shift + 1。
2. 拖动框住需要的区域，松开后截图在原位置停留；按 Esc 取消。普通截图只需要屏幕录制权限。
3. 默认在图片任何位置拖动，都能移动整张截图。滚轮或触控板上下滚动可缩放，双指捏合也可缩放。缩放保持比例，不改变导出像素。
4. 右键打开纯图标工具栏，悬停查看说明。点击图钉保持在其他应用上方，再点取消置顶；Esc 或叉号关闭截图，不自动返回主界面。

长截图生成后使用相同编辑器，过高的长图会先缩小到屏幕内。设置中可勾选「截图完成后自动钉在最上层」，该选项默认关闭。浮层窗口不会在退出应用后自动恢复；已保留的截图可从「历史截图」重新打开。

## 直接标注截图

工具栏第一排依次是移动整图、选择标注、画笔、箭头、矩形、圆圈、马赛克和文字；第二排是颜色、粗细 / 字号、撤销、重做、复制、置顶、保存和关闭。颜色菜单显示红、橙、黄、绿、蓝、紫、黑、白的实际色块，当前颜色带选中圈。

- **移动**：默认模式。标注过程中按住空格拖动，也可临时移动整张截图。
- **画笔 / 箭头 / 形状**：选择工具后拖动绘制。按 Shift 可绘制正方形或正圆。
- **选择标注**：点击已有标注后拖动移动；箭头两端有调整点。方向键微调，Shift + 方向键每次移动 10 像素，Delete 删除所选标注。
- **马赛克**：像画笔一样涂抹需要遮挡的位置；粗细按钮调整笔刷直径。导出 PNG 和复制时，马赛克实际合入图片像素；历史记录中的原图与马赛克仍可编辑。
- **文字**：点击图中位置输入，Return 提交。用选择工具移动文字，颜色和字号可在选中后调整。
- **颜色 / 粗细**：设置当前工具样式；选中标注时也可修改已有标注。马赛克忽略颜色，粗细表示覆盖直径。
- **撤销 / 重做**：图标按钮或 Command + Z / Command + Shift + Z。新操作会清除旧的重做分支，最多保留 60 步撤销记录。
- **复制 / 保存**：Command + C / Command + S，或点击对应图标。新截图保存为 PNG；从历史打开的截图会更新原记录，Option + Command + S 可另存 PNG。导出包含全部标注，保持原图分辨率，不包含工具栏或选中边框。

默认保存方式下，Esc 或叉号会丢弃尚未保存或复制的新截图及其临时结果；已入历史的版本、已导出的文件和剪贴板内容不会删除。选择「所有截图自动保留」时，关闭新截图会保留最终标注。从历史重新打开后，Esc 只放弃本次未保存的编辑，保留历史上次保存版本。关闭截图均不自动返回主界面，再次按截图快捷键会开始新框选。

需要重新打开主界面时，可点击菜单栏图标中的「打开 ScrollCap」。主界面「工作台」中的四边裁剪仍可使用；当前浮层标注独立于工作台原图。

## 历史截图与保存方式

主界面顶部可切换「工作台」和「历史截图」。历史列表显示每张截图的缩略图、日期、类型和像素尺寸，支持重新编辑、复制、另存 PNG、单项删除和全部删除。

在设置的保存方式中选择：

- **保存/复制后保留**：默认选项。保存或复制成功后才进入历史；直接按 Esc 或叉号关闭未保留的新截图，会将它丢弃。
- **所有截图自动保留**：采集结果生成后即加入历史，关闭这张新截图时保留最终标注，无需先导出文件。

从历史重新编辑时，原始图片和各个标注都会恢复，包括可以移动、调整或删除的马赛克。点击保存图标或按 Command + S 更新当前记录；复制也会更新当前记录，不会为同一张截图重复新增历史。Option + Command + S 将当前结果另存为 PNG。按 Esc 关闭会丢弃本次尚未保存的编辑，历史仍保留上次保存或复制的版本。

工作台裁剪原图的导出与浮层标注版本会分别成为独立历史。工作台保存原图不会覆盖浮层已保存的标注；需要保留标注版本时，请在对应浮层中保存或复制。

历史仅存放在本机 `~/Library/Application Support/ScrollCap/History`，退出和重新打开应用后仍可查看。**历史保留可编辑原图，因此其中的马赛克和其他遮挡可以移除；分享图片时请使用导出的 PNG。** 导出的 PNG 已合并所有标注，不附带原始图片或可编辑图层。

单项删除或全部删除会将对应历史移到系统废纸篓，可从废纸篓恢复。删除历史不会删除已经导出到其他位置的 PNG。

## 快捷键与设置

点击右上角「设置」，或按 Command + 逗号。应用运行时，全局快捷键可从其他应用调用：

| 动作 | 默认快捷键 |
| --- | --- |
| 普通截图 | Control + Shift + 1 |
| 长截图 | Control + Shift + 2 |
| 结束采集 / 取消处理 | Control + Shift + . |

点击对应录入框后直接按组合键，设置自动保存。Esc 取消录入，Delete 清除；「恢复默认」恢复三组默认键。组合键须包含 Control 或 Command，重复组合和部分系统保留组合会提示错误。录入期间会暂时停用截图快捷键，结束录入后恢复。

快捷键本身无需辅助功能权限；只有自动滚动需要。若其他应用占用了组合，请在设置中更换。关闭主窗口仍可使用快捷键，完全退出应用后快捷键停止工作。

## 截取完整聊天窗口

1. 打开要截取的聊天窗口，调整好大小和位置。选择「向下」；从最新消息向历史记录滚动时选择「向上 · 历史聊天」。
2. 点击「框选窗口并开始」，框住整个对话区域，包括标题栏和底部输入框。
3. 在预览中拖动上下两条线，让中间只包含真正会滚动的正文。保持勾选「把固定部分截进长图」。线外的顶部和底部会各保留一次。
4. 点击确认，开始先停 1 秒。每次滚动正文可见高度的 1/4～1/3，然后停约半秒，前后两屏保留至少一半相同内容。结束前停 1 秒，再点击浮动条上的结束按钮。不要拖动滚动条跳页，也不要改变窗口位置和大小。
5. 等待生成截图浮层，按需标注并保存或复制。需要四边裁剪、原视频或关键帧时，可从菜单栏打开主界面操作。

网页没有固定顶部或底部时，可以把相应边界拖到画面边缘；整个区域都在滚动时，点击「整个区域都滚动」。

这一版通过两条水平线区分固定区域和正文。框选时请避开固定的左侧会话列表；正文中间的悬浮弹窗、遮挡层目前不能单独分离。

## 自动滚动

1. 选择「自动滚动」，建议使用「慢速 · 推荐」，并开启屏幕录制及辅助功能权限。
2. 框选窗口、标记正文。确认后，鼠标定位到正文中央，工具自动小步滚动、停稳后继续。
3. 慢速每步约正文高度的 1/5，标准约 1/4；两种模式均保留充分重叠。选「向上 · 历史聊天」可向历史消息采集。
4. 连续三次检测到画面没有移动后自动结束。遇到加载或不稳定画面先等待，再判断是否继续。
5. 点击浮动条「结束并生成」可中途结束。移动鼠标离开滚动位置、切换应用、移动 / 缩放 / 关闭目标窗口都会停止。

自动模式只能滚动正文当前位置可到达的内容；折叠区域、分页跳转和网页动态替换不能视为同一条连续内容。输出仍通过原视频逐帧分析和接缝验证。

## 滚动速度与完整性

以中间真正滚动的正文高度为准，不包含固定标题和输入框。例如正文可见高度约 600 像素，每次滚动约 150–200 像素，停约半秒再继续；不必精确计时。开始、结束各停 1 秒，网页图片和消息加载完再继续，不要在一次采集中来回反向滚动。向历史消息滚动时先选「向上」。

2.2.1 起分析每个原视频帧，保留快速滚动中的中间画面，并在大步幅前保留桥接帧。上述节奏是便于操作的稳妥建议，不能弥补拖动滚动条造成的内容缺失。真正没有重叠时，预览会明确显示橙色「长图不完整」提示，请保存原视频。

## 主界面预览中裁剪

从菜单栏选择「打开 ScrollCap」，进入主界面的「工作台」。以下操作使用工作台的原图，不包含浮层编辑器中新增的标注。

- 默认进入裁剪状态。拖动四边、四角的小方块或边线调整范围，拖动选区内部可上下左右移动。暗色区域不会导出。
- 「适合宽度」便于阅读长图，滚动预览可到达底部；「全图」可同时看到四边；「100%」按屏幕像素查看细节，图像较大时可横向和纵向滚动。
- 右上角显示当前选区的实际像素尺寸。选区始终限制在原图内，不会反转。
- 点击「完成裁剪」查看裁剪结果，「调整裁剪」可继续编辑；「恢复原图」恢复完整范围。原图一直保留到下一次采集或退出。
- 保存 PNG 和复制都使用当前选区，即使还没点击「完成裁剪」。导出直接取原图像素，预览缩放不会改变导出清晰度。
- 裁剪仅影响主界面的图片导出，原视频、关键帧和接缝报告保持原始记录。

## 已有视频

点击「导入已有窗口视频」，选择不超过 5 分钟的视频，再标记正文区域。视频应只包含目标对话区域，滚动方向与应用设置一致。导入处理不需要屏幕录制权限，原文件不会被改写。

## 拼接方式与保存

应用先连续录制，再选择清晰帧，匹配重叠内容，并用 Apple Vision 识别文字位置，优先在空白处拼接。处理在本机完成，不需要账号或云端服务。画面文字来自原始视频，不由生成模型重新绘制。

高保真采集默认开启，文字更清晰，视频文件也较大；可关闭以节省空间。录制时间可设为 30–300 秒，原视频达到约 2 GB 时会停止。输出限制为 4000 万像素，正文高度不超过 60000 像素。

滚动太快、跳转或遮挡可能导致无法确认某段内容。此时会提示并生成已确认部分，原视频仍可保存。开始下一次或退出前，请保存或复制需要保留的长图，并另行导出视频、关键帧和报告；临时采集文件会清理，已入历史的截图会保留。

## 权限已开启却未识别

确认授权的是 Applications 中的「ScrollCap」，然后按 ⌘Q 完全退出并重新打开。正在运行的进程可能保留旧权限状态，仅关闭主窗口不等于退出。自行重新编译或更新本地签名版本后，macOS 可能要求重新授予屏幕录制权限。

2.3 的自动模式需要辅助功能权限。权限检查和滚动由同一个签名应用的短时进程执行，授权后回到应用会重新读取状态，避免当前进程保留旧结果。若更新本地签名版本后系统开关已开但仍未识别，请移除旧条目，再添加 Applications 中的 ScrollCap；应用不会代替你修改系统授权。手动模式不要求辅助功能。

当前测试包的临时签名绑定单次构建，更新后可能出现「旧开关已开，当前版本未授权」。这是应用身份变化，反复开关同一旧条目不一定有效。后续使用固定证书签名可使兼容更新沿用授权，构建配置见 [签名与更新授权](SIGNING.md)。
