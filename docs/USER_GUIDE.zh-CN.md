# ScrollCap · 整窗口长截图

像 FSCapture 一样保留聊天窗口的固定顶部和底部，中间的正文连续拼接。标题栏、工具栏、输入框各出现一次。支持网页和聊天窗口，默认手动滚动，也可以自动滚动。

## 安装

打开「ScrollCap-2.1.0-macOS-arm64.dmg」，把「ScrollCap.app」拖到 Applications。适用于 Apple 芯片 Mac、macOS 14 或更新版本。旧版「长截图」可以保留。

首次框选屏幕时，按提示在系统设置 → 隐私与安全性 → 屏幕与系统音频录制中允许「ScrollCap」。如系统要求，退出并重新打开应用。**手动模式不需要辅助功能权限**；自动滚动才需要相应权限。

新版使用独立的应用身份，旧版的权限不会自动转移。建议先安装到 Applications，再开启权限，之后始终从该位置启动。

## 截取完整聊天窗口

1. 打开要截取的聊天窗口，调整好大小和位置。选择「向下」；从最新消息向历史记录滚动时选择「向上 · 历史聊天」。
2. 点击「框选窗口并开始」，框住整个对话区域，包括标题栏和底部输入框。
3. 在预览中拖动上下两条线，让中间只包含真正会滚动的正文。保持勾选「把固定部分截进长图」。线外的顶部和底部会各保留一次。
4. 点击确认，回到聊天正文缓慢、连续地滚动。不要拖动滚动条跳过内容，也不要改变窗口位置和大小。完成后点击浮动条上的结束按钮。
5. 等待生成预览，点击「保存 PNG」或「复制」。也可以保存原视频及关键帧。

网页没有固定顶部或底部时，可以把相应边界拖到画面边缘；整个区域都在滚动时，点击「整个区域都滚动」。

这一版通过两条水平线区分固定区域和正文。框选时请避开固定的左侧会话列表；正文中间的悬浮弹窗、遮挡层目前不能单独分离。

## 已有视频

点击「导入已有窗口视频」，选择不超过 5 分钟的视频，再标记正文区域。视频应只包含目标对话区域，滚动方向与应用设置一致。导入处理不需要屏幕录制权限，原文件不会被改写。

## 拼接方式与保存

应用先连续录制，再选择清晰帧，匹配重叠内容，并用 Apple Vision 识别文字位置，优先在空白处拼接。处理在本机完成，不需要账号或云端服务。画面文字来自原始视频，不由生成模型重新绘制。

高保真采集默认开启，文字更清晰，视频文件也较大；可关闭以节省空间。录制时间可设为 30–300 秒，原视频达到约 2 GB 时会停止。输出限制为 4000 万像素，正文高度不超过 60000 像素。

滚动太快、跳转或遮挡可能导致无法确认某段内容。此时会提示并生成已确认部分，原视频仍可保存。开始下一次或退出前，请保存需要的长图、视频和关键帧；临时文件会清理。

## 权限已开启却未识别

确认授权的是 Applications 中的「ScrollCap」，然后完全退出并重新打开。正在运行的进程可能保留旧权限状态，仅关闭主窗口不等于退出。这个情况已经在实际使用中验证：完整重启同一版本后，自动模式恢复正常。自行重新编译后，应用签名会变化，macOS 可能继续缓存旧权限。必要时可仅重置新版辅助功能记录，再在系统设置中重新开启：

```sh
tccutil reset Accessibility io.github.arronfan23.scrollcap
```

手动模式不依赖这个权限。屏幕录制权限请通过系统设置检查与重新授权。

## 源码与验证

Sources/ScrollCap 文件夹包含 Swift / AppKit / SwiftUI 源码，双击 build.command 可重新构建。已通过 15 项基础拼接检查、21 项视频拼接检查，以及真实窗口连续录制与拼接测试；也验证了界面导入视频、拖动边界和生成 640 × 1800 长图。
