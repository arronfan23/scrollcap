# ScrollCap brand assets

## 设计

Logo 以连续折叠的白色 S 形纸带表达滚动内容，用两枚对角定位符表达截图。蓝色到绿色的渐变形成识别色，简洁的轮廓用于应用图标与仓库首页。

- `logo.png`：主 Logo / 图标，1024 × 1024 PNG。
- `logo-256.png`：仓库和文档的小尺寸版本。
- `../../Resources/AppIcon.icns`：macOS 应用图标，多尺寸封装。
- `prompt.txt`：最终图像提示词和制作方式。

Logo 使用内置 imagegen 生成；PNG 尺寸变换及 ICNS 封装使用 macOS 工具。素材随本仓库按 MIT 许可证发布，请避免以 ScrollCap 官方名义发布未经维护者确认的衍生构建。
