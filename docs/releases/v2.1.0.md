# ScrollCap 2.1.0 · 长截图

首次 GitHub 公开发布。面向网页和聊天窗口，固定标题与输入框各保留一次，中间正文连续拼接。

## 功能

- 原生 macOS 应用，支持手动与自动滚动，以及向上 / 向下采集。
- 连续视频采集和已有视频导入，清晰帧选择与本机 Vision 文字识别辅助接缝。
- PNG 保存、剪贴板复制、原视频 / 关键帧 / 分析报告导出。
- 全程本机处理，无账号、云端上传或遥测。
- 新 Logo 与应用图标，中文 / 英文文档和 MIT 开源许可证。

## 下载

Apple 芯片选择 `arm64`，Intel Mac 选择 `x86_64`。DMG 用于安装；ZIP 包含应用；SHA256SUMS 文件用于校验下载。

需要 macOS 14+。当前构建为本地签名，尚未进行 Apple Developer ID 签名或公证。

## 权限

将「ScrollCap.app」安装到 Applications 后授权。手动模式只需屏幕录制权限；自动滚动还需辅助功能权限。开启权限后请完整退出并重新打开应用，避免当前进程继续保留旧授权状态。

## 验证

15 项基础拼接检查与 21 项视频处理检查。已使用合成窗口素材验证上下方向、文字顺序、固定区域只保留一次、末帧覆盖、缺失重叠警告及取消处理。

## 当前限制

固定区域通过上下两条水平边界定义；框选时避开固定侧栏。正文中间的悬浮弹窗不能单独分离。请保持窗口位置不变并缓慢滚动，开始下一次或退出前保存需要的结果。
