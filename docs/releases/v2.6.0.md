# ScrollCap 2.6.0 · 可编辑的本机截图历史

普通截图和长截图现在都能保存在历史区域，随时重新打开继续标注。本次公开发布同时包含 2.1.0 之后的浮层编辑、快捷键、设置、裁剪与滚动拼接修复。

## 新增与改进

- **历史截图**：按日期、类型和尺寸浏览与搜索；重新编辑、复制、另存 PNG、单项删除或全部删除。
- **按需保留**：默认保存或复制成功后才进入历史。直接 Esc 或关闭新截图会丢弃未保留的内容；也可在设置中选择自动保留所有截图。
- **继续编辑**：历史保留原图和标注。Command + S 更新原记录，Option + Command + S 另存 PNG；Esc 放弃本次未保存修改。同一条截图反复保存不会重复入库。
- **原地截图浮层**：普通截图完成后停在框选位置，可拖动、滚轮缩放和置顶；长截图也可在浮层中编辑。Esc 关闭后不再自动返回主界面。
- **图标标注工具栏**：画笔、可调整端点的箭头、矩形、圆圈、马赛克、文字、撤销与重做；支持真实颜色预览和粗细调整，图标附带悬停说明。
- **设置与快捷键**：可自定义普通截图、长截图和结束采集的全局快捷键，配置普通截图自动置顶及历史保留方式。
- **长截图与权限修复**：四边拖动裁剪、逐帧视频分析与桥接关键帧、更保守的自动滚动和重叠匹配，以及更明确的权限反馈。
- **SMO 品牌与原生界面**：蓝绿色工作台，窗口名称为 ScrollCap，内置前往 GitHub 的 Star 按钮。

## 历史与隐私

全部处理在本机完成，无账号、云端上传或遥测。历史保存在本机 Application Support，含原图和可编辑标注，因此历史中的马赛克可以移除。分享时使用导出的 PNG：它是合并后的像素图，不附带原图或图层。

删除历史会将记录移到系统废纸篓，不影响已经导出的 PNG。

## 下载与升级

需要 **macOS 14 或更新版本**。Apple 芯片选择 `arm64`，Intel Mac 选择 `x86_64`；DMG 用于安装，ZIP 包含应用，SHA256SUMS 文件用于校验下载。

当前发布包为临时签名，尚未进行 Apple Developer ID 签名或公证。安装到 Applications 后授权屏幕录制；自动滚动还需辅助功能。更新后如权限开关已开却仍未识别，请从对应权限列表移除旧 ScrollCap，再添加 Applications 中的当前版本，最后完整退出并重新打开应用。详见[签名与权限说明](https://github.com/arronfan23/scrollcap/blob/v2.6.0/docs/SIGNING.md)。
